# Spina Bifida

Веб-приложение для анализа УЗИ-кадров плода на признаки, связанные со Spina Bifida: Flask API, React/TypeScript, SQLite и отдельный ML-worker. Приложение определяет плоскость и область интереса, оценивает качество кадра, показывает сигнал признаков патологии и тепловую карту Grad-CAM++.

Результат модели — предварительная техническая оценка, которая не заменяет клиническое заключение специалиста. Score модели не является калиброванной вероятностью диагноза.

Совместная разработка:

- [Yandex Cloud](https://yandex.cloud/ru);
- [Школа анализа данных](https://shad.yandex.ru/);
- [Благотворительный фонд «Спина бифида»](https://helpspinabifida.ru/);
- [НМИЦ АГП им. В.И. Кулакова](https://ncagp.ru/).

## Установка и использование

Начните с [установки с нуля](docs/rewrite/OPERATIONS.md) или [автоматического развёртывания в Yandex Cloud](docs/rewrite/YANDEX-CLOUD.md). Приложение работает на одной VM под Docker Compose, поддерживает CPU и NVIDIA GPU. YDB не требуется, Object Storage подключается по желанию.

Для анализа нужны обе версии моделей `v1`/`v2`: по пять файлов в каждой. [Скачайте десять весов из Object Storage](deploy/rewrite/models/README.md) и проверьте их по манифесту SHA-256. Готовые опубликованные Docker-образы не предполагаются: установка из исходников описана в руководстве.

После входа и принятия условий загрузите от одного до десяти JPEG/PNG-кадров или откройте четыре встроенных примера. Выберите `v1` или `v2`, запустите анализ и изучите плоскость, качество, признаки патологии, ROI и тепловую карту. К результату можно оставить обратную связь.

Первого администратора создают через CLI. Администратор управляет пользователями в `/admin`. При настроенном Yandex Cloud Postbox доступны регистрация с подтверждением email и модерацией, а также восстановление пароля; смена известного пароля доступна в профиле и без Postbox.

## Состав репозитория

| Каталог | Содержимое |
|---|---|
| `apps/backend/` | Flask API, аутентификация, SQLite, миграции, ML-конвейер, worker и тесты |
| `apps/frontend/` | React-интерфейс, переводы, четыре примера и тесты |
| `deploy/rewrite/` | Docker Compose, CPU/GPU-установка, Traefik, backup/restore и облачная автоматизация |
| `docs/` | Документация проекта, приложения и эксплуатации |
| `scripts/` | Общая проверка приложения |

ML-конвейер приложения использует YOLOv8 и DenseNet121/201; его архитектура, предобработка и контракт весов описаны в [документации](docs/rewrite/MODEL-PIPELINE.md). Репозиторий содержит инференс готовых моделей; материалы обучения в этот выпуск не входят.

Датасеты, разметка, CSV-manifests, веса, результаты запусков, пользовательские данные и секреты в Git не входят. Единственные исходные медицинские изображения — четыре примера в `apps/frontend/public/examples/`. Подробнее — [состав и границы проекта](docs/PROJECT.md).
